# mymusic

The PHP pages of my music collection on my site of 2006 and 2007: the list, the details and the forms, in two code
bases. A historical archive, kept read-only: the PHP code of its time: not safe to deploy today, kept for its history.

## History

| Date | Commit | Branch | |
|---|---|---|---|
| 2006-11-25 | 71c1f0a | `main` | mymusic: the list, details and forms |
| 2007-03-27 | b062ec2 | `mycol-2007-03` | mycol_new: a new start (the index and the database includes), a different code base |

The tables and data of the collection are not in this repository.

## How it was built

There was no version control then: in 2026 I turned the archived folders into commits, with their dates kept, one branch
per code base. The last commit on each branch sets LF line endings and indents with spaces.
